# Data dictionary - `data/processed/panel.parquet`

Generated by `python src/features.py`; do not edit by hand.

- Index: `date` (SPY trading day t), 8245 rows, 1994-01-27 -> 2026-10-30
- Every feature on row t is known at the **close of day t**; the trade is filled at the **open of t+1** and held to the **open of t+2**.
- Features are unscaled. FRED inputs use the latest value dated strictly before t.

## Labels, prices and helper columns

| column | definition | unit | known at | used by |
|---|---|---|---|---|
| `period` | 'warmup' / 'dev' / 'embargo' / 'test' from config.json['splits']; 'embargo' = last dev rows whose label uses test-period opens | label | - | row filter for B / C |
| `y_ret` | Open_(t+2) / Open_(t+1) - 1 (SPY adjusted) | decimal | open of t+2 | C: strategy and buy-and-hold return |
| `rf_annual` | DTB3 (value dated < t) converted from discount basis to bond-equivalent yield: 365 d / (360 - 91 d) | decimal per year | close of t | rate behind rf_daily |
| `rf_daily` | rf_annual x calendar days from open t+1 to open t+2 / 365 (3 days over a weekend); NaN on the last rows like the label | decimal per holding period | close of t (trading calendar is published in advance) | C: cash return; risk-free for y_exret |
| `y_exret` | y_ret - rf_daily | decimal | open of t+2 | B: main regression label |
| `y_up` | 1 if y_exret > 0 else 0 (NaN if y_exret is NaN) | 0/1 | open of t+2 | B: optional classification label |
| `px_open` | SPY open, split + dividend adjusted | USD (adjusted) | open of t | C: prices / checks |
| `px_close` | SPY close, split + dividend adjusted | USD (adjusted) | close of t | C: prices / checks |
| `ret_cc` | px_close_t / px_close_(t-1) - 1 (same values as feature rev_ret_1) | decimal | close of t | C: e.g. volatility-scaled benchmark |

## Missing values

- Features: none (rows before the end of the 252-day warm-up are dropped).
- `y_ret`, `y_exret`, `y_up`: last 2 rows are NaN (no future open yet).
