## 0. 一分钟版本

- **C 做了什么：** 把 B 模型每天的预测（“明天 SPY 比现金多赚多少”）变成仓位（“明天持有多少 SPY、多少现金”），扣掉交易成本，算出 2015–2026 年的表现，并和几个简单策略比较。
- **结论：** 在所用规则、1bp 成本和这段样本下，模型策略没有跑赢买入持有，也没有跑赢“同样规则、但用历史平均值当预测”。差距在统计上不显著。准确说法是：**没有检测到模型相对这些基准的稳健增量价值**（不要说成“证明模型没用”）。
- **主要原因：** 平均只持有约 66% 的 SPY，在大牛市里少赚；模型预测误差的改善集中在少数几个极端反弹日。
- **为什么仍能拿分：** 作业 PDF 第 1、4、6 节写明“看过程不看收益”（"Strong process with weak returns can earn a top grade"）。

## 1. 报告里需要先解释的名词

| 名词 | 一句话解释 |
|---|---|
| 仓位 `w` | 资金中投入 SPY 的比例。1 = 全部买 SPY，0 = 全部拿现金 |
| 超额收益 | 策略收益减去现金利息 |
| 买入持有 | 第一天全部买入 SPY，之后不动 |
| 交易成本（bp） | 每买卖 1 元付出的比例；1bp = 0.01% |
| 买卖价差 | 市场上最低卖价与最高买价之差，是交易成本的主要部分 |
| 换手 | 一年内仓位变化的总量 |
| 夏普比率 | 平均超额收益 ÷ 超额收益的波动，越高越好 |
| 最大回撤 | 从最高点到之后最低点的最大跌幅 |
| CE（确定性等价收益） | 把风险折算后的“等效无风险收益”，γ=3 |
| OOS R² | 和“每天都预测历史平均”相比，预测误差减少了多少 |
| bootstrap 区间 | 反复重抽历史数据看差距是否稳定；区间包含 0 = 现有证据分不清差距和随机波动 |
| β / α（CAPM） | β：策略收益对 SPY 涨跌的敏感度；α：扣除这部分后剩下的平均超额收益 |

## 2. 对应报告 §4.8：从预测到交易

**时间规则：** 第 t 天收盘后用当时已知的信息算预测和仓位 → 第 t+1 天开盘成交 → 持有到第 t+2 天开盘，获得这段收益。仓位和收益在同一行，不能再错开。**表格里的日期都是决策日 t；对应收益发生在 t+1 开盘到 t+2 开盘之间。**

**三种规则（都在看测试结果之前定好）：**

1. **主规则：成本感知均值—方差。** 预期收益越高买得越多，近期波动越大买得越少；只有调仓的好处超过手续费时才调仓。公式：最大化 `w·mu − γ/2·w²·σ² − c·|w − w_昨天|`，w 在 0–1 之间（只做多、不借钱）。
2. **对照：纯均值—方差（MV）：** `w = clip(mu/(γσ²), 0, 1)`。
3. **对照：只看方向：** 预测为正全买，为负全卖。

**参数：** γ = 3（敏感性 1、5）；`σ²` = 最近 20 天波动率的平方 ÷ 252；从全现金起步，结束时不平仓。

### 交易成本（报告用这段）

- **主情景 1bp**（每交易 1 元付 0.01%），敏感性 0/1/2/5/10bp。
- **依据：**
  - etf.com 一篇文章（Sumit Roy，2022-04-27；HTML 页面不显示日期，日期见该站文章的 Markdown 版本）给出 SPY 平均报价买卖价差 0.0032%，约 0.32bp，是全价差；
  - SPY 发行商 SSGA 的事前估计（截至 2026-06-30）：2,500 万美元订单、中午 12:00–12:30 用 VWAP 执行，价差成本（相对中间价）约 0.07bp + 冲击约 0.08bp，合计约 0.15bp。这是发行商数据，而且不是开盘成交。
- **为什么是 1bp：** 我们在开盘成交，1bp 约为报价价差的 3 倍，余量覆盖开盘竞价和冲击成本（A 的文档把这部分交给 C）。它是**研究假设**，不能写成实测成本。
- **成本也进入规则：** c 决定不交易区间的宽度，所以改成本也会改变仓位，不只是改费用。
- **历史记录（报告方法部分写一句即可）：** “The protocol was first frozen with a 5 bp main scenario; after checking SPY spread data we set 1 bp (after test results had been computed). 5 bp results are reported as a sensitivity scenario and archived.” 这是事实，必须保留；5bp 结果放在成本敏感性表里，正文主线用 1bp。

### 基准

| 基准 | 用来回答的问题 |

## 4. 对应报告 “Interpretation”：为什么输、学到了什么

**原因 1：持仓偏低。** 按会计恒等式拆分（不是因果证明）：主策略年化毛超额 = 持仓部分 8.0% + 择时部分 +0.5%，再减成本 0.3%；买入持有的持仓部分是 12.1%。

**原因 2：预测误差的改善集中在少数日子。** 测试期 OOS R² 0.27%；去掉决策日 2025-04-08（收益期 4 月 9 日开盘至 10 日开盘）后降到 0.15%，再去掉决策日 2025-04-04、2020-03-23 后为 −0.01%（`diag_oos_r2_concentration.csv`）。这些日子是按结果事后挑出来的，所以是**影响诊断**，说明结果对少数日子很敏感；正式评分仍用全部数据。

**原因 3：预测与收益的关系很快减弱。** 本样本中，预测与下一期收益的相关为 0.052，再往后一期为 0.014；只看方向的规则按当天信号交易时择时部分 +3.8%/年，同样仓位滞后一期为 −0.6%。**写法：** “在本样本中预测能力在额外滞后一期后迅速下降”，不要写“信号只有 1 天有效、所以必须天天交易”。

**原因 4：减仓多发生在高波动期（这是描述，不是归因）。** 减仓日平均波动率 20.1%，全期 14.7%。注意：`diag_exposure_cuts.csv` 里“预测非负，但风险调整后的不交易区间上界低于原目标仓位”这一类（169 天）只是规则的机械分支，其中 42 天波动率并没有上升，预测下降本身就会减仓。**报告和视频里不要说“这些减仓是波动上升造成的”。**2020 年疫情反弹期（决策日 3 月 24 日至 6 月 8 日），主策略平均仓位 0.11，收益 +4.8%，买入持有 +31.3%。

| | 1bp（主情景） | 5bp（敏感性） |
|---|---|---|
| 主策略夏普 | 0.61 | 0.54 |
| 对买入持有、历史平均、目标波动率的排名 | 都更低 | 都更低 |
| 对买入持有的年化超额差 | −3.9% [−8.2%, +0.1%]，不显著 | −4.6% [−8.7%, −0.8%]，显著 |
| 择时部分 | +0.5% | −1.3%（成本高时仓位更“粘”） |

### 盈亏平衡成本

- 主规则和 MV 规则即使 0 成本也低于买入持有（夏普 0.66 vs 0.72）。
- 只看方向的规则在成本低于约 3.7bp 时能追平（夏普）；但 0 成本下的优势区间 [−0.08, +0.35] 包含 0，验证期它反而最差。所以**不采用**，只作对照。

### 其他稳健性

- γ = 1/3/5：主策略夏普 0.63/0.61/0.59，都低于历史平均对照（0.72/0.74/0.73）。
- 模型消融：Ridge M1/M2/M3 夏普 0.61/0.65/0.72；R² 几乎相同（0.26%–0.29%），交易结果却差很多，所以不改选 M3。
- 验证期（2005–2014，含 2008）：主策略 0.52，买入持有 0.40，历史平均对照 0.59，目标波动率 0.59。冠军是在这些年份上选的，只算开发证据。

## 4A. 探索性扩展 1：高波动时不再自动减仓

**定位（必须写）：** 两个扩展都是看过测试期诊断后才提出的，属于**探索性分析**。版本先写进协议、只用验证期挑选，可以减少按测试结果择优，但不能消除“测试信息参与了想法形成”这一点，所以**不能当作独立的确认性证据**，也不替换主结果。**不要**在报告或视频里把它说成“完整研究循环 → 测试期检验”。

**故事：**
1. **发现：** 在波动最高的 20% 交易日里，模型说涨时实际平均每天 +14.6bp，说跌时 −10.8bp（验证期 +4.3 / −4.3bp），但主规则恰在这些日子仓位最低（0.49；验证期 0.38）。注意：验证期里最高波动组的“说涨减说跌”差距（8.6bp）和最低波动组一样大，所以“高波动时信号最有用”只在测试期成立，不要说成两期都成立。
2. **版本**（`docs/extension_vol_protocol.md`）：A 原规则；B 固定风险；C 风险封顶。参数只用评估区间之前的数据。
3. **结果：**

| 版本 | 验证期 夏普 / CE / 最大回撤 | 测试期 夏普 / CE / 最大回撤 |
|---|---|---|
| **A 原规则（验证期选中）** | 0.52 / 4.3% / −24% | 0.61 / 5.5% / −20% |
| B 固定风险 | 0.38 / 2.1% / −41% | 0.62 / 5.9% / −32% |
| C 风险封顶 | 0.36 / 1.9% / −38% | 0.69 / 6.8% / −31% |
| 买入持有 | 0.40 / 2.1% / −55% | 0.72 / 7.8% / −32% |

4. **结论：** 验证期按规则选中原规则（2008 年高波动后继续下跌，减仓起了保护作用：B/C 亏 23%/19%，A 亏 3%）。测试期不减仓更好（2020 年 B/C 约 +17%，A +3%），但 C 对 A 的夏普差 +0.08 [−0.06, 0.22] 不显著，且仍低于买入持有。高波动后是反弹还是续跌取决于时期。

**图：** `results/test/fig_ext_vol.png`、`results/val/fig_ext_vol.png`（并排放）。

## 4B. 探索性扩展 2：以买入持有为底仓的微调

**定位同 4A。**

**规则：** 默认持有 SPY，模型只在此基础上多买或少买：`w = 1 + d`，`d` 由“模型预测 − 历史均值预测”决定。版本：T1 [0.5, 1.0] 只减仓；T2 [0.5, 1.5]、T3 [0.75, 1.25] 可加杠杆（按国债利率借，偏乐观）。

**修订 R1（重要，报告别写错）：** 之前说“模型没学到东西时，这个策略就等于买入持有”，**这是错的**。从现金起步时，因为不交易区间，零信号下仓位会停在 0.595（T1/T2）或 0.75（T3）。现在每个版本都配了一个“同规则零信号对照”：
- “微调 − 零信号对照” = 模型的增量价值；
- “微调 − 买入持有” = 投资价值。

| 版本 | 验证期 夏普 / CE | 测试期 夏普 / CE / 最大回撤 | 测试期平均仓位 |
|---|---|---|---|
| **T1（验证期选中）** | 0.42 / 2.7% | 0.68 / 6.8% / −30% | 0.73 |
| T1 零信号对照 | 0.40 / 2.7% | 0.72 / 5.7% / −20% | 0.60 |
| 买入持有 | 0.40 / 2.1% | 0.72 / 7.8% / −32% | 1.00 |

- **T1 对零信号对照（测试期）：** 年化超额 +3.0% [+0.5%, +5.2%]（显著），但夏普 −0.03 [−0.15, +0.10]、CE +1.2% [−1.7%, +3.7%]（不显著）。即模型的微调提高了平均仓位、多承担了市场风险，多赚的收益经风险调整后不显著。验证期：超额 +2.3% [−0.5%, +4.7%]，夏普 +0.02 [−0.12, +0.18]。
- **T1 对买入持有：** 夏普差验证期 +0.02 [−0.12, 0.18]，测试期 −0.03 [−0.16, 0.10]。
- **结论：** 以买入持有为底仓能避免持仓过低，但没有检测到模型微调在风险调整后的稳健增量价值。

**图：** `results/test/fig_ext_tilt.png`、`results/val/fig_ext_tilt.png`（图中虚线灰色为 T1 零信号对照）。

**两个扩展合起来的一句话：** 针对已发现的两个问题做了两项探索性改进，都没有让模型在风险调整后稳定超越买入持有，结果与主结论一致。

### 学到了什么（视频结尾可用）

1. 预测准确度的小幅提高（OOS R² +0.27%）不等于交易价值，而且这点提高对少数极端日子很敏感；
2. 预测能力衰减得快时，交易频率和成本就是关键；
3. 在长期上涨的市场里，平均持仓偏低的代价很大；
4. 事先冻结规则、如实记录每一次变更，能防止我们采用只是事后看起来好的规则。

## 5. 研究纪律（报告里要写，评分重点）

- 规则和参数在计算任何测试期策略收益之前写进 `docs/protocol_partC.md` 和 `config_partC.json`，冻结时间 2026-11-08 21:31（UTC+8），哈希在 `results/freeze_log.json`。

  - 主成本 5bp → 1bp，发生在测试结果已知后（原结果存档）；

- 冻结前在验证期发现：成本 ≥ 约 3bp 时，“历史平均 + 成本感知”永远不买入，因此加了“历史平均 + MV”作为第二对照。1bp 下不出现这个问题。
- **不要**改动冻结记录或选择记录里的时间；时间线本身就是流程证据。

## 6. 局限（报告 limitations 段）

- 成本感知规则是单期（近视）规则，不是多期最优；它对上期目标仓位求解，而实际扣费按漂移后仓位计算。
- **记账是近似：** 换手考虑了价格漂移，成本直接从当期收益中扣；没有完整追踪扣费后现金与股票的调整。
- 成本是假设值（1bp），未模拟开盘竞价和冲击；主情景是看过测试结果后定为 1bp 的。
- 风险用收盘到收盘的波动率估计，收益按开盘到开盘计算。
- 验证期预测每年重估，测试期每月重估。
- 没有做逐个特征的贡献拆分（需要 B 每月的标准化参数和截距）；特征层面的解释来自 B 的系数路径和 M1/M2/M3 消融。
- 测试期是强牛市，预测误差的改善对少数极端日子很敏感，结论可能依赖市场环境。
- 两个扩展是探索性分析。

## 8. 如何运行代码与注意事项

### 8.1 运行前准备

- **文件夹结构不能变：** `partA/`、`partB/`、`partC/` 放在同一个上级文件夹。Part C 用相对路径读取 `../partA/data/processed/panel.parquet`、`../partB/data/predictions.parquet`、`../partB/results/partB/val_predictions_champion.parquet`。

- **环境：** Python 3（测试环境 3.10.12、pandas 2.3.3、numpy 2.2.6、matplotlib 3.10.9）。`pip install -r partC/requirements.txt`。
- **pyarrow：** 请确保装上。没有 pyarrow 时会改用 `src/mini_parquet.py`，但它需要系统 snappy 库（Linux：`libsnappy`；macOS：`brew install snappy`），没有就读不了数据（修正清单 R9 的检查环境就是这种情况）。

### 8.4 注意事项

1. **重跑会覆盖结果，但数字完全相同**（无随机性，bootstrap 固定 seed 5205），重跑是复现，不是重复使用测试集。
2. **不要删除或修改：** `results/freeze_log.json`、`results/ext_*_selection.json`、两个存档文件夹。扩展脚本遇到已有选择记录会保留，打印 “Selection already recorded and reproduced exactly by the current code/data; not overwritten” 属正常。验证期运行会核对已有选择记录能否被当前代码、数据和配置精确复现，并写出 `results/ext_*_selection_check.json`；测试期运行先核对这个文件。若提示 “NOT reproduced” 或 “stale” 而中止，说明数据、参数或策略代码被改过：**不要删除选择记录来绕过**，先找 C 核对。另外，预测文件若缺日期、重复、乱序或有非数值，主脚本会直接报错，这是有意的防护。每期的校准窗口记录在 `results/{val,test}/ext_*_calibration.json` 和 `run_meta.json`。
3. **不要改 `config_partC.json` 的参数。** 敏感性结果已在 `performance_by_cost.csv`、`performance_by_gamma.csv`。
4. 运行时可能出现 pandas 的 `FutureWarning`，可忽略。
5. 报告数字以 `results/test/*.csv` 为准。
