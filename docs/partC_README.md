### 交易成本：1bp

主情景按每单位单边换手收 1bp（0.01%）。依据如下：

- **外部数据：**
  - etf.com 的一篇文章（Sumit Roy，2022-04-27；HTML 页面不显示日期，日期见该站文章的 Markdown 版本）报告 SPY 平均报价买卖价差为 0.0032%，即约 0.32bp。这是买价与卖价之间的全价差。
  - SPY 发行商 SSGA 给出的事前估计（截至 2026-06-30）：一笔 2,500 万美元的订单，在中午 12:00–12:30 用 VWAP 执行，相对中间价的价差成本约 0.07bp，加上 0.08bp 市场冲击，合计约 0.15bp。发行商数据，且不是开盘成交。
- **1bp 的含义：** 我们在开盘成交。1bp 约为上述报价价差的 3 倍，余量用于覆盖开盘竞价和冲击成本（Part A 文档将这部分交给 C 的成本假设）。它是研究假设，不是 2015–2026 年开盘成交的实测成本。
- **团队约定：** Part A 建议 1–5bp 并写明由 C 决定；Part B 没有设定成本。
- **成本也进入规则：** 成本感知规则的不交易区间由 c 决定，所以改变成本不只是少扣费用，也会改变仓位路径。
- **历史记录（如实说明）：** 协议最初冻结时主情景为 5bp；查阅上述价差数据后，于 2026-11-09 改为 1bp，此时测试结果已经算出。5bp 的完整输出保存在 `results/archive_main5bp/`，5bp 也一直作为敏感性情景报告。

## 1bp 与 5bp 的比较（成本敏感性）

| 指标（测试期） | 1bp（主情景） | 5bp（敏感性） |
|---|---|---|
| 主策略夏普 / 年化平均超额 | 0.61 / 8.2% | 0.54 / 7.4% |
| 主策略年换手 / 成本拖累 | 31.3 / 0.31% | 6.1 / 0.31% |
| 主策略择时贡献 | +0.5% | −1.3% |
| 主 − 买入持有，年化超额差的区间 | [−8.2%, 0.1%] | [−8.7%, −0.8%] |
| 主策略 vs 买入持有、历史均值、目标波动率的排名 | 都更低 | 都更低 |

两种成本下，主策略相对各基准的排名方向相同，但证据强度不同：5bp 下对买入持有的年化超额差在 95% 水平上显著，1bp 下不显著。成本更高时，不交易区间更宽、仓位更“粘”，择时贡献由正转负。

## 结论（1bp 主情景）

1. **在所用规则、成本和样本下，没有检测到 champion 预测相对指定基准的稳健增量价值。** 主策略的各项指标都低于买入持有、历史均值对照和目标波动率；现有证据不足以把这些差距与抽样波动区分开，但这不等于证明两者等价。
2. **差距主要对应持仓偏低。** 按会计恒等式拆分：年化毛超额 = 平均持仓部分 8.0% + 择时部分 0.5%，再减成本 0.3%；买入持有的持仓部分是 12.1%。这是记账上的拆分，不是因果证明。
3. **预测与收益的关系很快减弱。** 本样本中，`corr(mu_t, y_exret_{t+k})` 在 k=0 时为 0.052，k=1 时为 0.014；只看方向的规则按当天信号交易时择时部分为 +3.8%/年，同样仓位滞后一期后为 −0.6%。我们没有估计最优交易频率。
4. **测试期 OOS R² 的改善集中在少数日子，对这些日子很敏感。** 去掉决策日 2025-04-08（收益发生在 4 月 9 日开盘到 10 日开盘之间）后 R² 由 0.27% 降到 0.15%；再去掉决策日 2025-04-04 和 2020-03-23 后为 −0.01%。这些日子是按结果事后挑出的，属于影响诊断；正式评分仍使用全部真实行情。
5. **减仓多发生在高波动期（描述统计，不是归因）。** 减仓日平均 `vol_rv_20` 为 20.1%，全期 14.7%。`diag_exposure_cuts.csv` 按规则的分支给减仓日贴的是**机械标签**：“预测非负，但风险调整后的不交易区间上界低于原目标仓位”这一类有 169 天，其中 42 天当天波动率并不比前一天高，即预测下降本身也会触发减仓，所以这张表不能当作“波动上升导致减仓”的独立归因。决策日 2020-03-24 至 06-08（收益期为 3 月 25 日开盘至 6 月 10 日开盘）主策略平均仓位 0.11，收益 +4.8%，买入持有 +31.3%。
6. **验证期结果只能当开发证据。** 验证期（含 2008 年）主策略夏普 0.52，高于买入持有的 0.40，但低于历史均值对照（0.59）和目标波动率（0.59）。冠军模型是在这些年份上选出的。

## CAPM alpha（冻结后的评估，不改规则）

`python src/capm.py --period test`（或 `val`）：`r − rf = α + β(r_SPY − rf)`，标准误用 Newey-West（滞后 8 期），α 按 ×252 年化。

| 策略 | 测试期 α（年化，95% 区间） | 测试期 β | 验证期 α（年化，95% 区间） | 验证期 β |
|---|---|---|---|---|
| 主：成本感知 champion | −0.2% [−3.6%, 3.2%] | 0.69 | +2.6% [−1.8%, 7.1%] | 0.57 |
| MV champion | −0.0% [−3.5%, 3.5%] | 0.69 | +3.3% [−1.2%, 7.8%] | 0.57 |
| 成本感知 历史均值 | +1.0% [−2.5%, 4.5%] | 0.67 | +2.6% [−1.7%, 6.9%] | 0.40 |
| MV 历史均值 | +1.3% [−2.3%, 4.9%] | 0.65 | +3.2% [−1.1%, 7.4%] | 0.40 |
| 目标波动率 | +1.1% [−1.6%, 3.9%] | 0.70 | +3.0% [−0.4%, 6.5%] | 0.58 |
| 200 日均线 | +1.7% [−3.2%, 6.6%] | 0.50 | +2.9% [−2.7%, 8.5%] | 0.31 |

**解读：** 两个时期都没有发现统计显著的 α（不显著不等于证明 α 为零）。测试期主策略对 SPY 的回归敏感度 β 约 0.69（实际平均目标仓位为 0.66）。在控制这一市场敏感度后，主策略没有显著的超额收益，与收益拆分的结论一致。

## 探索性扩展（事后分析，不替换主结果）

两个扩展都是在看过测试期诊断后提出的，属于**探索性分析**。版本在重新计算之前写进协议，并只用验证期选择，以减少直接按测试表现择优；但这不能消除测试信息参与了假设形成这一问题，因此它们**不作为独立的确认性样本外证据**。

### 扩展 1：高波动时不再自动减仓

协议：`docs/extension_vol_protocol.md`。

**依据（`diag_vol_regime.csv`）：** 测试期里，在 `vol_rv_20` 最高的 20% 交易日，模型的方向信号对后续收益的区分最大，但主规则的仓位最低；验证期里最高一组的区分（约 8.6bp/天）并不比最低一组（约 8.6bp/天）大，所以这个依据主要来自测试期。

| 最高波动 20% 的日子 | 模型说涨 → 实际收益 | 模型说跌 → 实际收益 | 主规则平均仓位 |
|---|---|---|---|
| 测试期 | +14.6bp/天 | −10.8bp/天 | 0.49 |
| 验证期 | +4.3bp/天 | −4.3bp/天 | 0.38 |

**版本：** A 原规则；B 把 σ 固定为校准期中位数；C 以校准期第 75 百分位为 σ 上限。验证期用 1994–2004 校准（0.154 / 0.209），测试期用 1994–2014（0.144 / 0.201）。只看验证期 CE 选择。

| 版本 | 验证期 夏普 / CE / 最大回撤 | 测试期 夏普 / CE / 最大回撤 | 测试期择时部分 |
|---|---|---|---|
| **A 原规则（验证期选中）** | **0.52 / 4.3% / −24%** | 0.61 / 5.5% / −20% | +0.5% |
| B 固定风险 | 0.38 / 2.1% / −41% | 0.62 / 5.9% / −32% | +1.9% |
| C 风险封顶 | 0.36 / 1.9% / −38% | 0.69 / 6.8% / −31% | +2.2% |
| 买入持有 | 0.40 / 2.1% / −55% | 0.72 / 7.8% / −32% | — |

- 按预先规则保留原规则 A。2008 年 B/C 为 −23% / −19%，A 为 −3%；2020 年 B/C 约 +17%，A 为 +3%。
- 高波动之后是反弹还是继续下跌，在两个时期不同，所以“高波动时该不该减仓”没有一个两期都成立的答案。
- C 对 A 的测试期夏普差为 +0.08，95% 区间 [−0.06, 0.22]，且 C 仍低于买入持有。

### 扩展 2：以买入持有为底仓的微调

协议：`docs/extension_tilt_protocol.md`。规则：`w = 1 + d`，`d` 是 `(mu − mubar)/(γσ̄²)` 的成本感知解；σ̄ 为校准期中位数，1bp，γ = 3。版本：T1 [0.5, 1.0]（只减仓），T2 [0.5, 1.5]、T3 [0.75, 1.25]（杠杆按国债利率借入，偏乐观）。

**同规则零信号对照（修订 R1）：** 原文档称“模型预测等于历史均值时，策略就是买入持有”，这是错的。从现金起步时，不交易区间半宽约 0.40，零信号下仓位会停在 0.595（T1/T2）或 0.75（T3），不会回到 1。所以现在为每个版本加了“增量信号恒为 0、其余完全相同”的对照：
- “微调 − 零信号对照”衡量模型的增量价值；
- “微调 − 买入持有”衡量投资价值。

| 版本 | 验证期 夏普 / CE / 最大回撤 | 测试期 夏普 / CE / 最大回撤 | 测试期平均仓位 | 测试期择时部分 |
|---|---|---|---|---|
| **T1 [0.5, 1.0]（验证期选中）** | **0.42 / 2.7% / −47%** | 0.68 / 6.8% / −30% | 0.73 | +1.6% |
| T1 零信号对照 | 0.40 / 2.7% / −39% | 0.72 / 5.7% / −20% | 0.60 | 0 |
| T2 [0.5, 1.5] | 0.40 / 0.5% / −59% | 0.67 / 7.5% / −41% | 0.89 | +3.8% |
| T3 [0.75, 1.25] | 0.41 / 1.7% / −57% | 0.71 / 8.0% / −36% | 0.94 | +2.0% |
| 买入持有 | 0.40 / 2.1% / −55% | 0.72 / 7.8% / −32% | 1.00 | — |

**T1 相对零信号对照（模型的增量）：**

| | 年化超额差 | 夏普差 | CE 差 |
|---|---|---|---|
| 验证期 | +2.3% [−0.5%, 4.7%] | +0.02 [−0.12, 0.18] | +0.0% [−4.1%, 3.1%] |
| 测试期 | +3.0% [0.5%, 5.2%] | −0.03 [−0.15, 0.10] | +1.2% [−1.7%, 3.7%] |

- 测试期 T1 的年化超额显著高于零信号对照，主要因为模型的微调把平均仓位从 0.60 提高到 0.73，即承担了更多市场风险；经风险调整后（夏普、CE）差异不显著。
- T1 相对买入持有：夏普差验证期 +0.02 [−0.12, 0.18]，测试期 −0.03 [−0.16, 0.10]。
- 结论：以买入持有为底仓能避免持仓过低，但没有检测到模型微调在风险调整后的稳健增量价值。

## 稳健性与消融（预设，不据此改选）

- **γ = 1 / 3 / 5（1bp）：** 主策略夏普 0.63 / 0.61 / 0.59，均低于 MV 历史均值（0.72 / 0.74 / 0.73）。
- **模型消融（1bp，同一主规则）：** Ridge M1 / M2 / M3 夏普 0.61 / 0.65 / 0.72；Elastic Net 0.68；LASSO 退化为历史均值，0.72。三个 Ridge 的 OOS R² 几乎相同（0.26%–0.29%），交易结果却相差 0.11，说明交易结果对预测的细微差别很敏感，所以**不改选** M3。

## 局限

- 单期（近视）成本规则不是多期最优；它对上期目标仓位求解，而实际扣费按漂移后的仓位计算，两者是近似关系。
- **记账是近似：** 换手考虑了持有期内价格变化带来的仓位漂移，成本直接从当期收益中扣除；没有完整追踪扣费后现金与股票的自融资调整。对小成本而言影响很小，但不是完全精确的交易记账。
- 成本是假设情景（1bp），没有模拟开盘竞价细节和大额冲击；主情景是在测试结果已知后由 5bp 改为 1bp 的（见“交易成本”一节）。
- 风险代理用 close-to-close 波动率，而标签是 open-to-open。
- 验证期预测每年重估，测试期每月重估。
- 没有做逐个特征的贡献拆分：需要 B 每月重估时的标准化参数和截距，系数文件里没有。特征层面的证据来自 Part B 的系数路径（短期反转为主）和 M1/M2/M3 消融。
- 事件窗口和年度表按**决策日**划分，对应的收益发生在下一个开盘到再下一个开盘之间（表中已列出实际收益期）；2026 年只到 10 月 28 日（决策日）。
- 两个扩展是由测试期诊断启发的探索性分析，不是独立的确认性证据。
