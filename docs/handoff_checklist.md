## 1. 作业真正要求交付什么

全组最终提交一个包：

- 15–25 页 PDF 报告，包含团队名称、全体成员和简短贡献说明；评分 25 分。
- 15–25 分钟视频，展示数据构建、拟合、验证、扣成本样本外评估及解释；评分 10 分。
- 源代码 ZIP 或 GitHub 链接，包含 README、依赖文件、可运行脚本、固定设置和精确运行命令。代码是必交内容，评分表没有为其单列第三个分值。

这些页数和时长是全组要求，不是让 C 单独写 15–25 页或录制同等时长。C 当前文件夹提供其中的交易、评估和解释部分。

作业没有要求逐次修改日志、文件哈希、精确冻结时间，也没有要求 CAPM、bootstrap、额外策略或每项诊断都必须出现。不要为了增加材料数量而压缩核心方法和结果的说明。
